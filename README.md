=============================================================================

1. PROJECT OVERVIEW

Project ACRP is a specialized resource planning tool designed for 
agricultural cooperatives in Davao Oriental. It ensures resource 
consistency by enforcing a distribution limit (3 sacks per hectare) 
and maintains digital records for auditing and emergency support.

2. SYSTEM FEATURES

- Security: Caesar Cipher encryption (+3 Shift) for password storage.
- Password Complexity: Supports special characters (e.g., @, #, $).
- Input Masking: Implemented 'Silent Masking' with an asterisk (*) 
  feedback reveal to protect credentials.
- Validation: Regex patterns for Numeric IDs and PH Mobile Numbers.
- Role-Based Access: Separate menus for Admin and Staff roles.

3. HOW TO RUN

- Ensure Java JDK is installed.
- Open Command Prompt and navigate to the 'src' folder (if applicable).
- Compile: javac ACRPSystem.java
- Run: java ACRPSystem
